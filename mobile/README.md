# Мобильное приложение «Свои»

Flutter 3.50 (Dart 3.14), платформы: Android, iOS, веб.

## Что уже есть

- Вход через VK ID и Яндекс ID (берём только номер телефона), кнопки появляются, если они подключены на сервере.
- Вход по номеру: звонок-сброс (код — последние 4 цифры номера), запасной вариант — SMS. Таймер повтора.
- Регистрация: имя, дата рождения (только 18+), пол, город, два отдельных согласия.
- Цели. «Без обязательств» закрыта, пока возраст не подтверждён через Госуслуги.
- Интересы: поиск по каталогу и выбор по категориям, уровень и «ищу партнёра», от 3 до 50.
- Фильтры для каждой цели: пол, возраст, минимум общих интересов, «только с проверенным фото», рост и вес (в романтических целях), привычки, питание, знак зодиака, религия; у критериев — «обязательно» или «желательно».
- Лента: анонимные карточки по выбранной цели, «Интересно» / «Пропустить», экран «Это взаимно!» → сразу в переписку.
- «Совпадения» (новые взаимные интересы, счётчик на вкладке) и «Чаты»: переписка с подсказкой для первого сообщения, анкета собеседника, жалоба (в том числе «похоже на несовершеннолетнего»), блокировка, завершение общения.
- Анкета: о себе, до трёх ответов на вопросы, привычки, питание, рост и вес, телосложение, знак зодиака, религия (с отдельным согласием); у каждого блока выбор «кто видит».
- Профиль: анкета, цели, интересы, «Скрыть меня от моих контактов» (на сервер уходят только хеши номеров), «Поддержать проект», выход.
- «Рядом»: объяснение приватности, видимость на 1/3/8 часов или пока открыто приложение, радиус, «только подтверждённым», кнопка «Исчезнуть», радар с интервалами («до 500 м»), личные зоны «там, где я сейчас». Геопозиция отправляется раз в минуту и только пока вкладка открыта.

## Запуск

```bash
cd mobile
flutter pub get

# Демо-режим: без сервера, код всегда 1234, люди в ленте ненастоящие,
# каждый второй интерес взаимный, на первое сообщение собеседник отвечает
flutter run

# С настоящим сервером
flutter run --dart-define=API_URL=http://10.0.2.2:8080   # эмулятор Android → localhost
```

Для входа через VK ID при сборке Android нужен ID приложения VK ID (схема возврата `vk<ID>`):
`flutter build apk --android-project-arg vkidClientId=12345678`.

## Проверки

```bash
flutter analyze
flutter test                 # весь путь регистрации в демо-режиме + клиент API
flutter test test_screens    # снимки экранов с настоящими шрифтами → build/screenshots/
```

## Устройство

| Файл | Что внутри |
| --- | --- |
| `lib/api/api.dart` | Интерфейс API и `ApiException` |
| `lib/api/http_api.dart` | Клиент сервера (`backend/`) |
| `lib/api/demo_api.dart` | Демо-режим: данные в памяти, каталог из `assets/data/catalog.json` |
| `lib/state.dart` | Сессия и шаг регистрации; токен хранится в `shared_preferences` |
| `lib/location.dart` | Геопозиция: устройство (geolocator) или фиксированная точка в демо |
| `lib/theme.dart` | Цвета и шрифты из макетов, подписи целей и привычек |
| `lib/screens/` | Экраны |

Каталог `assets/data/catalog.json` — копия `backend/internal/catalog/catalog.json`; при изменении каталога копируйте файл.

Справочник городов `assets/data/cities.json` — github.com/hflabs/city (CC BY-SA 4.0), копия `backend/internal/cities/cities.json`.

Шрифты Manrope и Unbounded — под лицензией SIL OFL 1.1 (тексты лицензий в `assets/fonts/`).
