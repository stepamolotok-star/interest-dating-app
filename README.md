# Приложение знакомств по интересам

> «Найди своих людей по интересам». Название приложения пока не утверждено.

Приложение помогает найти людей с общими увлечениями: для отношений, дружбы,
совместного хобби, встреч «без обязательств» (18+, с подтверждением возраста
через Госуслуги) и небольших компаний по интересам. Главная особенность — режим
«Рядом»: уведомление, когда поблизости оказывается подходящий человек, при этом
никакие личные данные не раскрываются без взаимного согласия.

## Структура репозитория

| Папка | Что внутри |
| --- | --- |
| `backend/` | Сервер на Go: API, подбор, каталог интересов, геолокация |
| `backend/migrations/` | SQL-миграции PostgreSQL |
| `mobile/` | Мобильное приложение на Flutter (следующий этап) |
| `docs/` | Решения и заметки по архитектуре |

## Как запустить сервер локально

Нужны Go 1.24+ и Docker.

```bash
docker compose up -d          # PostgreSQL и Redis
cd backend
go test ./...                 # тесты
go run ./cmd/api              # сервер на http://localhost:8080
```

Проверка: `curl http://localhost:8080/healthz`,
поиск по каталогу: `curl "http://localhost:8080/v1/interests/search?q=мото"`.

## Принципы, которые нельзя нарушать в коде

1. **Точные координаты никогда не уходят другим пользователям.** Наружу отдаётся
   только интервал расстояния («до 500 м», «до 1 км», …), посчитанный между
   центрами геоячеек.
2. **Взаимность.** Человек попадает в выдачу, только если оба проходят
   обязательные фильтры друг друга. Видеть других в «Рядом» может только тот,
   кто сам видим.
3. **Раскрытие по согласию.** Каждый уровень профиля открывается только при
   согласии обеих сторон и закрывается одним действием.
4. **Личные зоны.** Внутри зон «Дом», «Работа» и других пользователь невидим.
5. **Цель «Без обязательств»** доступна только с подтверждённым возрастом 18+
   через Госуслуги и проверенным фото.
6. **Данные граждан РФ хранятся на серверах в России** (152-ФЗ).
