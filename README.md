# Приложение знакомств по интересам

> «Найди своих людей по интересам». Название приложения пока не утверждено.

Приложение помогает найти людей с общими увлечениями: для отношений, дружбы,
совместного хобби, встреч «без обязательств» (18+, с подтверждением возраста
через Госуслуги) и небольших компаний по интересам. Главная особенность — режим
«Рядом»: уведомление, когда поблизости оказывается подходящий человек, при этом
никакие личные данные не раскрываются без взаимного согласия.

## Структура репозитория

| Папка | Что внутри |
| --- | --- |
| `backend/` | Сервер на Go: API, подбор, каталог интересов, геолокация |
| `backend/migrations/` | SQL-миграции PostgreSQL |
| `mobile/` | Мобильное приложение на Flutter: вход, регистрация, интересы, лента — см. `mobile/README.md` |
| `docs/` | Решения и заметки по архитектуре |

## Как запустить сервер локально

Нужны Go 1.25+ и Docker.

```bash
docker compose up -d          # PostgreSQL и Redis
cd backend
export DATABASE_URL=postgres://app:app@localhost:5432/app
export REDIS_URL=redis://localhost:6379/0
go run ./cmd/api              # сервер на http://localhost:8080, миграции применятся сами

# тесты; с базой и Redis — все (тестовые база и Redis будут очищены!)
TEST_DATABASE_URL=postgres://app:app@localhost:5432/app_test \
TEST_REDIS_URL=redis://localhost:6379/15 go test -p 1 ./...
```

Проверка: `curl http://localhost:8080/healthz`,
поиск по каталогу: `curl "http://localhost:8080/v1/interests/search?q=мото"`.

## API (готово)

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET | `/v1/interests/categories` | Категории каталога |
| GET | `/v1/interests/{id}/children` | Подкатегории и увлечения |
| GET | `/v1/interests/search?q=` | Поиск увлечений с синонимами |
| POST | `/v1/auth/start` | `{phone, method}` — звонок-сброс (по умолчанию) или `sms` |
| POST | `/v1/auth/verify` | `{phone, code}` → `{token, registered}` |
| POST | `/v1/auth/register` | Имя, дата рождения, пол, город, согласия (нужен токен) |
| POST | `/v1/auth/logout` | Выход |
| GET | `/v1/me` | Свой аккаунт |
| GET/PUT | `/v1/me/profile` | Поля профиля; религия — только с `consents.special_category` |
| GET/PUT | `/v1/me/visibility` | Видимость полей: `anonymous`, `after_match`, `matching_only`, `hidden` |
| GET/PUT | `/v1/me/interests` | Увлечения с уровнем и «ищу партнёра» |
| GET/PUT | `/v1/me/goals` | Цели; «Без обязательств» — только с Госуслугами и проверкой фото |
| GET/PUT | `/v1/me/prefs/{goal}` | Фильтры «обязательно / желательно» для цели |
| GET | `/v1/feed?goal=` | Лента анонимных карточек, лучшие сверху |
| POST | `/v1/feed/{user_id}/interest` | «Интересно» (можно отметить общий интерес); взаимно → совпадение |
| POST | `/v1/feed/{user_id}/skip` | «Пропустить» на 30 дней |
| GET | `/v1/matches` | Совпадения: раскрытый профиль собеседника и последнее сообщение |
| GET/POST | `/v1/matches/{id}/messages` | Переписка (`?before=` — листать назад); в первом сообщении без ссылок и контактов |
| POST | `/v1/matches/{id}/end` | «Разорвать совпадение» — доступ закрывается сразу для обоих |
| POST | `/v1/users/{id}/block` | Блокировка: взаимная невидимость и разрыв совпадений |
| POST | `/v1/users/{id}/report` | Жалоба; угрозы, преследование, слежка и «похоже на несовершеннолетнего» — срочные |

### Режим «Рядом» (нужен `REDIS_URL`)

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET/PUT | `/v1/nearby/visibility` | Видимость: `off`, `foreground`, `background`, `timed` (`hours` 1–12), радиус 300/1000/3000/10000 м, «только проверенным», «скрыть от контактов» |
| POST | `/v1/nearby/disappear` | «Исчезнуть» — мгновенно везде |
| GET/POST | `/v1/nearby/zones` | Личные зоны (от 500 м), внутри человек невидим |
| DELETE | `/v1/nearby/zones/{id}` | Удалить зону |
| POST | `/v1/nearby/location` | `{lat, lon, mocked}` → координаты сразу превращаются в ячейку ~150 м на 10 минут |
| GET | `/v1/nearby/radar?goal=` | Люди рядом: анонимные карточки с интервалом расстояния |
| GET/POST | `/v1/me/templates` | Шаблоны поиска с уведомлениями: порог оценки, лимит в день, тихие часы |
| DELETE | `/v1/me/templates/{id}` | Удалить шаблон |

Цели: `family` (серьёзные отношения и семья), `romance`, `casual`, `friendship`,
`hobby`, `talk`, `travel`, `likeminded`. Про детей — привычки `has_kids`
(yes/no) и `wants_kids` (yes/no/unsure), по ним работают фильтры.

В режиме разработки (`APP_ENV=dev`) никто не звонит: код пишется в лог сервера.

## Принципы, которые нельзя нарушать в коде

1. **Точные координаты никогда не уходят другим пользователям.** Наружу отдаётся
   только интервал расстояния («до 500 м», «до 1 км», …), посчитанный между
   центрами геоячеек.
2. **Взаимность.** Человек попадает в выдачу, только если оба проходят
   обязательные фильтры друг друга. Видеть других в «Рядом» может только тот,
   кто сам видим.
3. **Раскрытие по согласию.** Каждый уровень профиля открывается только при
   согласии обеих сторон и закрывается одним действием.
4. **Личные зоны.** Внутри зон «Дом», «Работа» и других пользователь невидим.
5. **Цель «Без обязательств»** доступна только с подтверждённым возрастом 18+
   через Госуслуги и проверенным фото.
6. **Данные граждан РФ хранятся на серверах в России** (152-ФЗ).
